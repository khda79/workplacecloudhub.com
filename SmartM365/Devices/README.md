# SmartM365 Devices

This folder groups SmartM365 tools that run on, diagnose, repair, notify, or manage Windows endpoints.

## Content

- `DeviceRebootManager/`: localized WPF restart notification app for device restart governance.
- `DeviceRegistrationTool/`: local GUI and CLI diagnostics for Intune enrollment, Hybrid Join, and Entra device registration.
- `EndpointDiagnosticsAnalyzer/`: endpoint diagnostics analyzer for Intune Device Diagnostics ZIP files and local captures.
- `SmartIntuneHybridJoinToolkit/`: PsExec/LOT toolkit for Hybrid Entra Join and Intune enrollment repair.
- `SmartIntuneRemediation/`: Intune remediation scripts plus CLI and GUI manager.

Runtime logs, exports, LOT folders, local configuration files, and local memories stay outside Git through the repository ignore rules.
