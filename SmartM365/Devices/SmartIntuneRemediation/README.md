# Smart Intune Remediation

Workspace for SmartM365 Intune remediation scripts and the tools used to manage them.

## Organization

- `IntuneRemediationScripts/`: detection, remediation, diagnostic, and action scripts organized by Intune scenario.
- `IntuneRemediationManager/`: delegated interactive CLI and WPF GUI used to publish, compare, export, and manage Intune remediation packages.
