Comment réduire la taille de votre boîte aux lettres :
1
Supprimez les e-mails inutiles
Identifiez et supprimez les anciens messages, les pièces jointes volumineuses et les courriers dont vous n'avez plus besoin.
2
Videz le dossier "Courrier indésirable"
Les spams conservés augmentent votre quota. Videz ce dossier régulièrement.
3
Sauvegardez vos pièces jointes importantes
Sauvegardez les pièces jointes dont vous avez besoin sur votre lecteur réseau, OneDrive ou SharePoint Online, puis supprimez les e-mails correspondants.
4
Videz le dossier "Éléments supprimés"
Les messages supprimés restent stockés dans ce dossier jusqu'à sa purge. Videz-le : clic droit sur le dossier puis "Vider le dossier".
