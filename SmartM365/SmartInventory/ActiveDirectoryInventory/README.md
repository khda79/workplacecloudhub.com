# Active Directory Inventory

Active Directory inventory and reporting scripts.

## Scripts

- `SmartM365-ActiveDirectory-Inventory.ps1`: full AD inventory across domains, combined CSV generation, duplicate checks, weekly inventory history, and daily AD computer/user reports.
- Use `SmartM365-ActiveDirectory-Inventory.ps1 -ReportOnly` to regenerate daily reports from existing consolidated inventory CSV files without a live AD scan.

## Daily Reports

Daily computer and user stats are now generated by the inventory script from the consolidated inventory CSV files:

- `AD_Computers_DailyStats.csv`
- `AD_Users_DailyStats.csv`

Useful settings in `SmartM365-ActiveDirectory-Inventory.local.json`:

- `EnableDailyReport`: defaults to `true`.
- `DailyReportAllowedOS`: defaults to Windows 7/8/10/11 patterns.
- `DailyReportInactiveDays`: defaults to `90`.
- `EnableDailyReportLock`: defaults to `true` to avoid appending duplicate daily rows.
- `DailyReportLockRoot` and `DailyReportLockName`: configure the success lock location/name.

## Weekly History

The inventory script can keep one weekly snapshot of the consolidated AD inventory CSV files.

- `EnableWeeklyHistory`: defaults to `true`.
- `WeeklyHistoryFolderPath`: defaults to `{{DataAllRootPath}}\ActiveDirectory\Inventory\WeeklyHistory`.
- `WeeklyHistoryRetentionWeeks`: defaults to `52`.
- `DeleteTemporaryPerDomainCsv`: defaults to `true`; per-domain temporary CSV files are deleted after consolidation.
