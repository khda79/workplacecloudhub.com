# On-Premises Mailboxes

Exchange 2016 local mailbox inventory and reporting scripts.

## Scripts

- `SmartM365-Exchange-Local-Mailboxes-Inventory.ps1`: detailed mailbox, permissions, statistics, archive, retention, and mobile device inventory.
- `SmartM365-Exchange-Local-Mailboxes-Report.ps1`: mailbox reporting built from local Exchange mailbox inventory outputs.
