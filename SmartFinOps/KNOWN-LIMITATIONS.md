# SmartFinOps Workplace 1.5.0-beta.1 — Beta limitations

This beta is decision support for controlled evaluation. It is not production certification, licensing advice, or an automated license-removal tool.

- All evidence comes from existing local CSV exports. No Graph, Exchange, AD, Intune, Azure, Citrix or LinkedIn connection is made. This release does not validate a live tenant or collector permissions.
- Required activity, identity and license sources must be loaded and fresh before removal/downgrade potential is quantified. A matching aggregate activity row is required per user; F3 valuation additionally requires numeric mailbox and OneDrive storage. Missing evidence is not zero usage. Optional absent activity lanes still limit coverage.
- Source freshness uses the oldest valid report-refresh timestamp across all rows. Any blank, malformed or future timestamp in a refresh column makes freshness unknown. File modification time is a fallback only when the column does not exist; a copied file is not proof that collection is recent. Default maximum age: 72 hours. Sources are separate snapshots, not an atomic tenant snapshot.
- `-ValidateOnly` checks headers, presence and timestamps without retaining full row sets; it streams refresh dates when present. Duplicate identities and numeric value validation require a full analysis. Its successful exit means the validation completed, not that all sources passed. Inspect DataQuality status and freshness.
- Invalid schemas, duplicate or blank identities in canonical user/mailbox or tenant-SKU tables are excluded. Duplicate license assignments are consolidated into one decision per normalized UPN. Renamed UPNs, anonymized reports and cross-tenant copies cannot be reliably reconciled; supply exports for one tenant only.
- The E3/F3 model covers `SPE_E3` and `SPE_F1` only. Simultaneous E3 and F3 and conflicting directory states require review. Other SKU variants, add-ons and contractual bundles are not priced as removable seats from generic inactivity.
- Frontline eligibility, retention, legal obligations, application dependencies and actual business requirements require human validation. Empty hold/archive states exclude mailbox conversion; CSV attributes do not cover all Purview features or legal requirements.
- OneDrive and mailbox figures follow the existing binary 2 GB thresholds. Shared-mailbox review uses below 45 GB, 45 to below 50 GB, and at least 50 GB bands. Capacity and storage strings must be valid nonnegative numbers. Exported numeric CSV values use invariant decimal points.
- Prices remain the historical indicative France EUR excluding VAT baseline dated **2026-07-18**. They are not newly verified September quotes. The E3/F3 average across offers with and without Teams is a prioritization approximation, not a tenant entitlement price. Use validated local contract-price overrides. Other currencies are rejected in this beta; no FX conversion is implemented.
- Savings potential is a scenario, never realized savings. Monthly E3 removal is unit price; E3-to-F3 is E3 minus F3; annual value is monthly value times 12. Capacity reuse is separate cost avoidance and must not be added to savings. Mailbox conversion is a supporting action with no incremental value. Row counts in diagnostic findings are not distinct licenses, users or devices.
- `LicenseOptimization.csv` contains diagnostic findings, not additive financial opportunities. Its legacy `EstimatedMonthlyWaste` column stays empty; `ReferenceMonthlyUnitPriceEUR` is reference pricing only. Use consolidated UserLicenseDecision and ValueOpportunities for financial scenarios.
- Reports are English. Site guides are available in EN/FR/IT/ES/DE/AR. HTML presents aggregates but may disclose paths and environment metadata; detailed CSVs contain identities and operational data. Treat outputs as confidential. Empty result CSVs may be zero-length; use Summary/DataQuality to interpret them.
- Two runs sharing one current output directory can overwrite current files. Unique archive run IDs preserve individual evidence; use separate tenant/output directories for concurrent runs.
- No installer, automatic updater, Gallery package or live tenant qualification is included. The code-signing certificate must be trusted on the evaluation host for AllSigned execution.

Licensing references consulted on 2026-09-09: [Microsoft shared-mailbox guidance](https://learn.microsoft.com/en-us/microsoft-365/admin/email/about-shared-mailboxes?view=o365-worldwide) and [Microsoft France enterprise plans](https://www.microsoft.com/fr-fr/microsoft-365/enterprise/microsoft-365-plans-and-pricing). These do not replace the customer's contract or establish a new price baseline.
