# Citrix Cloud

Reserved area for Citrix Cloud and Citrix DaaS API-based inventory scripts.

Citrix Cloud scripts should use the Citrix Cloud API model and must stay separate from on-premises Delivery Controller and StoreFront SDK assumptions.

## Planned Areas

- `SmartInventory/DaaS/`: Citrix DaaS site, delivery, machine, session, policy, and application inventory.
- `SmartInventory/Monitor/`: Citrix Cloud Monitor and historical session data exports.
- `SmartInventory/CloudConnectors/`: Cloud Connector inventory and health posture.
