# Citrix On-Premises

Read-only inventory scripts for on-premises Citrix Virtual Apps and Desktops, StoreFront, and Citrix Licensing environments.

## Content

- `SmartInventory/CVAD/`: CVAD site, delivery, machine/session health, policy, and hosting/power inventory scripts.
- `SmartInventory/StoreFront/`: StoreFront configuration inventory scripts.
- `SmartInventory/Licensing/`: Citrix licensing configuration inventory scripts.

On-premises scripts use the locally installed Citrix PowerShell SDK and optional `-AdminAddress` for Delivery Controller targeting.
