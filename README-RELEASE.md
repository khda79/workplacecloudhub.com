# SmartWorkplaceIntelligence 1.0.0

This distribution contains the public Power BI project, preparation components,
neutral configuration templates and documentation. Its source baseline is Git
commit `1d96e294be086f804dfd03f1a621a7c8a9b805a8`.

The SmartM365 files included here support preparation but do not constitute the
complete SmartInventory collector distribution. Install the corresponding
SmartM365/SmartInventory components separately before collecting evidence.

The persona and site configuration workbooks retain their generic configuration
and blank input sheets; their example test rows have been removed. Review and
configure classifications for your environment. CountryReference.csv is a
generic reference list. No customer evidence or demonstration datasets are
included. See product documentation for prerequisites, configuration and use.

The README page count was updated and the two workbook templates were neutralized
for this distribution; all other baseline files are from the specified commit.
The historical thematic report profiles are not qualified for this master.

Offline PBIR validation: zero errors, 84 warnings with schema validation disabled.
Power BI Service deployment and refresh were not validated for this release.
