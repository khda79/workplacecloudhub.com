# Governance Inventory

Azure estate and governance inventory scripts.

## Scripts

- `SmartAzure-AzureEstate-Inventory.ps1`: exports the baseline Azure estate across management groups, subscriptions, regions, resource groups, resources, locks, and providers.
- `SmartAzure-PolicyCompliance-Inventory.ps1`: exports Azure Policy assignments, definitions, initiative definitions, exemptions, policy state details, and compliance summaries.
